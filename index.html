1. Concept Explanation

Entity-Relationship Model to SQL

An Entity-Relationship (ER) model is used to represent the structure of a database using entities, attributes and relationships. The ER model can then be converted into a relational schema, where entities become tables, attributes become columns, and relationships are represented using foreign keys or separate relationship tables depending on their cardinality.

This website demonstrates this conversion interactively. Users define entities and attributes, specify relationships and cardinalities, visualize the ER model, and generate SQL CREATE TABLE statements.

Basic Conversion Rules

  • Each entity is converted into a relational table.
  • Entity attributes become table columns.
  • A primary-key attribute identifies records in a table.
  • One-to-many relationships are represented using foreign keys.
  • Many-to-many relationships require a separate junction table.

2. Draw.io ER Diagram Import

Importing an Existing ER Diagram

The application also supports importing a standard ER diagram created using Draw.io. The uploaded diagram is analyzed to identify entities, attributes, relationships and cardinalities.

Rectangles are interpreted as entities, ovals as attributes, diamonds as relationships and connectors as associations between diagram elements. The extracted ER model is then passed to the same conversion process used for manually entered diagrams.

This allows an existing Draw.io ER diagram to be converted directly into SQL without manually entering the complete model again.

For best results, use standard ER notation when creating the Draw.io diagram.

Help

Step-by-step guide to using the ER → SQL Generator.

What does this website do?

This application allows users to create an Entity-Relationship model by entering entities, attributes and relationships. It visualizes the ER diagram and generates SQL CREATE TABLE statements from the model.

An existing ER diagram can also be imported from Draw.io and converted into the same ER model and SQL output.

Built-in Examples

Use the Built-in Examples dropdown on the Dashboard to load predefined ER models. Five examples are provided covering university management, company management, online shopping, hospital management and university course registration.

Draw.io ER Diagram Import

You can upload a standard Draw.io ER diagram using the Import Draw.io Diagram option on the Dashboard.

The application analyzes the diagram and attempts to identify entities, attributes, relationships and cardinalities before converting the detected model into SQL.

For best results, use rectangles for entities, ovals for attributes, diamonds for relationships and connectors between the corresponding elements.

Step 1 — Add an Entity

Enter the name of the entity, such as Student. Then enter its attributes separated by commas.

Example: student_id, name, email, dob

Click + Add Entity.

Step 2 — Add Relationships

Select the first entity, enter the relationship name, select the second entity and choose the appropriate cardinality.

Supported cardinalities are: 1:1, 1:N, N:1 and M:N.

Step 3 — Add Relationship Attributes

If the relationship itself has attributes, enter them in the Relationship Attributes field separated by commas.

Step 4 — Review the ER Diagram

The diagram represents entities using rectangles, attributes using ovals and relationships using diamonds. Diagram elements can be moved using drag and drop.

Step 5 — Zoom the Diagram

Use the + button to zoom in and the − button to zoom out. Use Reset Zoom to return to 100%.

Step 6 — Generate SQL

Click Generate SQL →. The application converts the ER model into SQL CREATE TABLE statements.

Step 7 — Review the Output

The generated SQL is displayed in the Generated SQL section. You can use Copy SQL to copy the generated code.

Validation

The Validation section displays messages when an input is missing or invalid and confirms successful operations.

Download

Use the Download button in the top navigation to generate a report containing the entered model, processing information, intermediate information and generated SQL.

Day / Night Mode

Use the button in the top-right corner to switch between Day Mode and Night Mode.
